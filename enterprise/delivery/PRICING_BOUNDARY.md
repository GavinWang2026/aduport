# 报价与交付边界

适用角色：销售、售前、实施报价  
目的：统一「卖什么 / 不卖什么 / 怎么加购」，避免范围蔓延。

---

## 1. 标准私有化 SKU（建议口径）

| SKU | 包含 | 典型交期 | 备注 |
|-----|------|----------|------|
| **企业标准包** | 离线镜像、安装脚本、验收清单、一机一码 License、远程部署协助、首年维保（按 SLA） | 出包后 **3–7 天**可装机验收 | 默认 **OCR 关**、病毒扫描关 |
| **标准包 + 扫描 OCR** | 上项 + MinerU（及约定环境下的 PaddleOCR-VL）说明与回归样张 | +1–3 天（视 GPU/模型） | 见 [OCR.md](../OCR.md) |
| **标准包 + 病毒扫描** | 上项或标准包 + ClamAV 集成启用与 fail-closed 验收 | +0.5–1 天 | 客户需提供/允许安装 ClamAV |
| **驻场实施** | 现场安装、培训、陪同验收 | 按人日 | 差旅另计 |

金额由商务填写；本文只定边界，不定死价。

---

## 2. 标准包明确包含

- 格式转换能力（以当时版本 `/api/formats` 为准）  
- 中文 PDF 导出可检索（验收 B2）  
- 内网离线运行（docling offline；模型随全量镜像或约定挂载）  
- 多 API Key 租户隔离（任务列表 / 持久化按租户）  
- License 绑定机器与到期日  
- 验收用例 B1–B8、B10–B11（B9 仅 OCR 加购）  

---

## 3. 标准包明确不包含（需加购或变更单）

| 项目 | 说明 |
|------|------|
| SaaS 计费 / 支付 / 自助开通 | 不在私有化范围 |
| 对象存储多租户网盘 | 非本品默认能力 |
| 客户存量扫描件准确率承诺到「某商业 OCR」同等 | 可做样张 POC，不作无上限保证 |
| 无限页全书 OCR | 默认 `OCR_MAX_PAGES` 限制；全书需评估算力与工期 |
| 定制格式 / 专用版式算法 | 按人日报价 |
| 与 OA/AD/SSO 深度对接 | 变更单 |
| 源码托管与二次开发知识产权独享 | 另议 |
| 非约定 OS/CPU 架构 | 如仅交付 amd64 却要求 arm64 原生 |

---

## 4. 验收与付款建议节奏

1. **合同生效** → 预付（许可 + 部分实施）  
2. **镜像移交 + 装机冒烟** → 中款  
3. **ACCEPTANCE 签字** → 尾款  
4. **维保** → 按年（可与许可捆绑）  

争议以验收清单勾选结果为准；未在清单内的「观感类」问题进入需求池，不阻塞尾款（除非合同另写）。

---

## 5. 售前必问清单

- 部署架构：单机 Docker / K8s？amd64 还是 arm64？  
- 是否必须完全离线？模型是否允许构建机下载后打入镜像？  
- 是否需要扫描件 OCR？有无 GPU？日均页量？  
- 是否需要病毒扫描？能否装 ClamAV？  
- 租户数量与 Key 发放方式？  
- License 期限与机器台数？  
- 是否要现场培训 / 驻场？  

---

## 6. 竞争话术边界（对内）

- **卖点：** 数据不出内网、可验收、可绑定机器、中文 PDF 可交付、格式面宽。  
- **不夸大：** 不承诺任意版式 PDF「完美还原」；不承诺替代专用双栏杂志排版引擎。  
- **路径：** 先标准包签约 → 用客户样张做可选 OCR POC → 再加购。
