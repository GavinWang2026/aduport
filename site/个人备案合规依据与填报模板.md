# 个人名义建站 · 合规依据与备案填报模板

> 结论：**可以，合法，零费用，无障碍。**
> 本文件只回答"为什么能做"和"怎么填表"，不涉及商业化（商业化主体问题见 `../.workbuddy/memory/`）。

---

## 一、三条法条依据（原文）

### 1. 《互联网信息服务管理办法》（国务院令第 292 号）第四条

> 国家对**经营性**互联网信息服务实行**许可制度**；对**非经营性**互联网信息服务实行**备案制度**。
> 未取得许可或者未履行备案手续的，不得从事互联网信息服务。

**这一条是整个问题的答案。** 制度设计上就分了两档，我们要走的是"备案"那一档。
个人拿不到"许可"（ICP 经营许可证，主体要求为公司），但**"备案"本来就是为非经营性网站设的**——
这不是"个人被排除在外"，而是"个人恰好落在这一档里"。

### 2. 《非经营性互联网信息服务备案管理办法》（原信息产业部令第 33 号，2024 年工信部令第 68 号修订）第五条

> 在中华人民共和国境内提供非经营性互联网信息服务，应当依法履行备案手续。
> ……本办法所称在中华人民共和国境内提供非经营性互联网信息服务，是指在中华人民共和国境内的**组织或个人**利用通过互联网域名访问的网站……提供非经营性互联网信息服务。

🔑 **"组织或个人"——个人被明文写进备案主体。这是最直接的依据，不需要任何解释。**

### 3. 同办法第三条、第八条

- 第三条：拟从事非经营性互联网信息服务的，应当向其**住所所在地**省通信管理局履行备案手续
- 第八条：可以**委托接入服务经营者（阿里云 / 腾讯云 / 华为云等）代为履行备案手续**
  → 所以实际操作中你不需要自己去跑管局，在服务商后台提交即可

## 二、为什么 AduPort 明确属于"非经营性"

判定的核心不是"有没有服务"，而是**有没有经营性收入**。

| 判定项 | AduPort 现状 | 结论 |
|---|---|---|
| 是否收费 | Landing 页 + 免费 Demo，**全页不标价格**（见 `index.html`） | 无偿 |
| 是否广告营利 | 无 | 无偿 |
| 是否代销/分成 | 无 | 无偿 |
| 是否有交易闭环 | 无购物车、无会员、无站内支付 | 无 |
| 内容性质 | 开源项目介绍 + 技术文档 + 公开共享的转换能力 | 公开性、共享性 |

→ **无偿 + 公开共享 = 非经营性**，走备案制，无需许可。

> ⚠️ 定性会翻转的唯一开关是「**站内**完成收费闭环」。
> 即使未来商业化，只要保持"站内只展示、交易在站外（合同 + 对公转账 / 邮件询价）"，
> 网站本身仍可维持非经营性备案。**翻转的临界点是站内下单/支付/开通会员。**

## 三、前置审批排查（33 号令第十一条）

> 拟从事**新闻、出版、教育、医疗保健、药品和医疗器械、文化、广播电影电视节目**等互联网信息服务……应经有关主管部门审核同意。
> 拟从事**电子公告服务**的，还应提交电子公告服务专项备案材料。

对照 AduPort：

| 类别 | 是否涉及 | 说明 |
|---|---|---|
| 新闻 / 出版 / 教育 / 医疗 / 药品 / 文化 / 广电 | ❌ 全不涉及 | 纯技术工具 |
| **电子公告服务（BBS）** | ⚠️ **必须避开** | 见下 |

🔴 **硬约束：站点不得加评论、留言板、论坛、用户发帖功能。**
一旦有，就属于"电子公告服务"，需要**专项备案**并接受额外监管，
个人备案几乎拿不到——这是最容易被无意间踩到的前置审批门槛。
`site/index.html` 当前无任何交互输入（除 Demo 上传），**必须保持**。

## 四、备案后必须做的两件事（33 号令第十三条）

1. 网站开通时，在**主页底部中央位置标明备案编号**
2. 在备案编号下方**链接工信部备案管理系统网址**（供公众查询核对）

> 未按规定放置的，责令改正并处 5 千元以上 1 万元以下罚款。
> → `site/index.html` 页脚已预留备案号位，上线时替换即可。

## 五、备案填报模板（可直接抄）

### 5.1 网站名称（🔴 最高频驳回点）

禁用词：**中国 / 中华 / 国家 / 国际 / 企业 / 公司 / 集团 / 有限公司 / 资讯 / 科技 /
贸易 / 协会 / 俱乐部 / 合作社 / 工作室**；
不能是**纯数字或纯字母**；≥4 个汉字；不能含个人姓名；
不能含行业属性词（如"法律""装修"）；不能含"官网""博客""网"等宽泛词。

⚠️ **`AduPort` 是纯字母，不能直接做备案网站名。** 需另起中文名。候选：

| 候选 | 合规性 | 备注 |
|---|---|---|
| 文档格式转换技术笔记 | ✅ 稳妥 | 首推，纯技术描述，无行业属性 |
| 文档交换技术研究 | ✅ 稳妥 | 次选 |
| 开源文档工具分享 | ✅ 合规 | "开源"为中性描述 |
| 桥接文档格式 | ⚠️ 有风险 | "桥接"可能被判定为无意义组合 |

### 5.2 网站简介（模板）

```
个人技术分享站点。记录文档格式转换工具 AduPort 的开发过程与技术文档，
提供公开的免费格式转换演示。非经营性网站，不涉及新闻、出版、教育、
医疗、药品、文化、广电等需前置审批的内容，不提供电子公告服务，
不从事任何经营性活动。
```

> 要点：① 开头写"个人技术分享"；② 明确"非经营性"；
> ③ **主动声明不涉及前置审批类目**；④ **主动声明不提供电子公告服务**。
> 简介里禁提：论坛 / 社区 / 电商 / 交易 / 支付 / 下载站。

### 5.3 服务类型勾选

勾选 **"其他"** 或 **"技术服务"** 一类，避免勾到"电子商务""信息发布平台"等敏感项。
若系统要求选"网站语言" → 中文（即使页面主体为英文也选中文，减少人工复核阻力）。

## 六、流程、时间与成本

| 阶段 | 时长 | 说明 |
|---|---|---|
| 服务商初审 | 1–2 工作日 | 阿里云 / 腾讯云后台提交 |
| 人脸核验 | 即时 | App 刷脸 |
| **工信部短信核验** | **24 小时内** | 🔴 约 10% 的人栽在这一步，超时自动退回 |
| 管局审核 | 5–20 工作日 | 33 号令第十二条：材料齐全应在 20 个工作日内予以备案 |
| **合计** | **约 2–4 周** | 费用 **0 元** |

**材料**：身份证正反面、域名证书、本人实名手机号（**170/171 虚拟号段直接退回**）、
应急联系电话（不能与主号相同）。广东/上海/北京非本地户籍需居住证。
🔴 **域名持有者必须与备案主体（本人）一致**——不一致是最常见驳回原因。

## 七、🔴 两条会让人白等一个月的坑

### 1. 备案期间网站必须关闭

审核期内域名不得对外开放，只能显示"备案中"页。
**一旦被发现对外开放，列入黑名单，暂停备案资格半年至一年。**

→ 这决定了正确节奏：**先用境外托管免备案上线，同时并行提交备案，批下来再切境内。**

### 2. 服务器位置决定要不要备案

| 服务器位置 | 工信部 ICP 备案 | 公安联网备案 |
|---|---|---|
| 中国内地 | ✅ 必须 | ✅ 需要 |
| 中国香港 / 澳门 / 台湾及境外 | ❌ **不需要** | 实践中按接入商要求 |

→ GitHub Pages / Cloudflare Pages 属境外，**今天就能拿到可分享链接，完全合法**。

## 八、一句话总结

> **《非经营性互联网信息服务备案管理办法》第五条明文把"个人"列为备案主体；
> AduPort 站点无偿、公开、无交易闭环、不涉前置审批、不提供电子公告服务，
> 五个条件全部落在非经营性区间内——所以个人名义建站不是"勉强可行"，而是制度设计的本意。**

唯一需要动脑的是那个**中文网站名**（不能用纯字母 `AduPort`），
唯一需要等的是**2–4 周审核期**（期间用境外托管先跑）。
