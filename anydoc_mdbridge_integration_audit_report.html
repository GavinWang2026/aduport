四、融入架构（一个程序，而非两个）

md‑bridge 程序▸ 包含 ▸ backend/.venv（Python 运行时）▸ 内置 ▸ mdbridge_native._doc
(vendored anydoc Rust 编译的 .so)
  • 源码期：native/anydoc/src/ 是 md-bridge 仓库内的子模块式目录（78 个 .rs / ~24k 行），随仓库版本管理，无外部 PyPI 拉取。
  • 构建期：build_native.sh 用 maturin 把它编为 abi3 扩展，--no-index 离线装进同一 venv。
  • 运行期：anydoc_bridge.py 经 import mdbridge_native._doc 直接调用，与 md-bridge 原生 importer 共享 DocumentModel，统一降级契约。
  • 结论：anydoc 的代码已不再是外部依赖，而是 md-bridge 自身的一部分——满足 BOSS「融入成一个代码程序」的硬性要求。
